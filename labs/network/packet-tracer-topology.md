# Packet Tracer Tutored Activity – Logical & Physical Topology Exploration

## Objective

Completed a guided Cisco Packet Tracer activity to understand how network devices are arranged, connected, and visualized through both logical and physical topology modes.

---

## Tools Used

- Cisco Packet Tracer 8.x+

---

## Overview

This practical exercise focused on exploring a sample network environment using Cisco Packet Tracer. The activity helped build foundational knowledge of network structure, device communication, and topology visualization.

---

## Key Concepts Covered

- Logical Topology  
- Physical Topology  
- Routers  
- Switches  
- End Devices  
- Connectivity Paths  

---

## Tasks Performed

- Opened and reviewed the Packet Tracer activity file.
- Explored the logical view to understand network connections.
- Switched to physical mode to inspect real-world device placement.
- Identified network devices and cable relationships.
- Observed how traffic may move across the environment.

---

## Key Learnings

- Logical mode shows how devices communicate.
- Physical mode represents real deployment layout.
- Routers connect separate networks.
- Switches connect devices inside local networks.
- Network visibility is essential for troubleshooting.

---

## SOC Relevance

Understanding topology is valuable for SOC analysts when investigating:

- Suspicious traffic flow
- Unauthorized device communication
- Lateral movement paths
- Segmentation weaknesses
- Incident scope within a network

---

## Requirements

- Cisco Packet Tracer
- Basic networking knowledge

Completed as part of networking and SOC foundation learning.
